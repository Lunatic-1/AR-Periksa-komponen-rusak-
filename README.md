# AR-Periksa-komponen-rusak-

## Deskripsi
Aplikasi Flutter untuk melakukan pemeriksaan komponen kerusakan dengan teknologi Augmented Reality.

## Prasyarat
- Flutter SDK versi ^3.13.1
- Android SDK (untuk menjalankan di Android)
- Xcode (untuk iOS, jika dikembangkan pada macOS)
- Chrome (untuk web)
- Visual Studio Build Tools (untuk Windows)

## Memulai Proyek
```bash
git clone <url-repo-anda>
cd AR-Periksa-komponen-rusak-
flutter pub get
```

## Menjalankan Aplikasi
- **Android**: `flutter run -d android`
- **iOS**: `flutter run -d ios`
- **Web (Chrome)**: `flutter run -d chrome`
- **Windows**: `flutter run -d windows`

## Catatan
- Pastikan emulator atau perangkat terhubung dan di‑setup dengan benar.
- Untuk mengubah aset model AR, letakkan file pada folder `assets/models/` dan deklarasikan di `pubspec.yaml`.
